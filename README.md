# 재 너머

소금 지고 고개 넘는 이야기. 브라우저에서 도는 작은 오픈월드 도트 RPG입니다.

늦가을, 갯마을 소래의 소금장수가 되어 한내 장터를 지나 검은재 너머 너와골까지 갑니다.
가는 순서는 정해져 있지 않습니다. 갯가에서 게를 잡아도 되고, 솔밭에서 숯을 떼다 팔아도 되고,
고개부터 올라가 봐도 됩니다. (낮에는 안 넘어가집니다. 이유는 가 보면 압니다.)

## 실행

설치할 것 없습니다. `index.html`을 브라우저로 열면 됩니다.
폰트 파일을 못 읽는 브라우저 설정이라면 폴더에서 아무 정적 서버나 띄우세요.

```
python3 -m http.server 8000
```

## 조작

| | 키보드 |
|---|---|
| 걷기 | 방향키 / WASD |
| 치기 | Z / J |
| 말 걸기 · 살피기 | X / K / Enter |
| 쥔 것 먹기 · 던지기 | C / L |
| 쥔 것 바꾸기 | Q |
| 구르기 (구르는 동안 무적) | Space / Shift |
| 봇짐 · 할 일 · 지도 | Esc / I / Tab, 지도는 M |
| 소리 끄기 | 0 |

터치 기기에서는 화면에 버튼이 뜹니다.
장승 앞에서 살피면 기록됩니다. 저장은 브라우저에 한 칸입니다.

## 들어 있는 것

- 이어진 지도 한 장(160×120칸)과 굴 하나. 갯가, 염전, 갈대밭, 논, 솔밭, 절터, 고개, 산골.
- 낮과 밤. 밤에만 나오는 것, 밤에만 열리는 길이 있습니다.
- 장사. 물건값이 마을마다 달라서 싸게 떼다 비싸게 넘길 수 있습니다.
- 할 일 일곱 가지, 적 여덟 종, 고갯마루의 그것 하나.

## 안 죽이고 가는 길

싸움은 피할 수 있게 만들었습니다.

- 적은 기가 꺾이면 덤비지 않고 달아납니다. 그때 더 치지 않으면 살려 보낸 것으로 칩니다.
- 들개·늑대·멧돼지는 코앞에서 먹을 것을 쓰면(C) 받아 물고 물러납니다.
- 굴에 사는 것들은 팥을 맞으면 달아납니다.
- 고갯마루의 그것은 이기는 길, 묵으로 달래는 길, 한 대도 안 치고 버티는 길이 따로 있고 뒷일이 다릅니다.
- 잡은 수와 보낸 수는 봇짐에 적히고, 몇몇 사람의 말과 마지막 장면이 그에 따라 달라집니다.
- 장독, 우물, 허수아비 같은 것도 살필 수 있습니다. 쓸모는 없습니다.

## 비워 둔 것

자신 없는 부분은 흉내 내지 않고 비웠습니다.

- **음악이 없습니다.** 효과음만 코드로 냈습니다. 곡은 그럴듯하게 쓸 자신이 없어서 넣지 않았습니다.
- **집 안이 없습니다.** 문은 그림입니다. 사람들은 다 마당에 나와 있습니다.
- **이야기는 소금을 넘기면 끝납니다.** 그 뒤는 돌아다닐 수만 있고 새 사건은 없습니다.
- **사람이 처음부터 끝까지 해 보지 않았습니다.** 대화·가게·전투·보스·저장은 자동 스크립트로 한 번씩 돌려
  확인했지만, 난이도와 물건값이 재미있는지는 손으로 검증하지 못했습니다. 숫자는 `js/data.js`와
  `js/entities.js` 맨 위에 모여 있습니다.
- **도트는 걷기 두 장면이 전부입니다.** 휘두르는 몸동작, 마을 사람이 걷는 모습은 없습니다.
- 게임패드, 설정 화면, 언어 선택은 없습니다.

## 파일

```
index.html        껍데기와 터치 버튼
js/core.js        난수, 입력, 효과음, 글자 찍기, 저장
js/art.js         그림 전부 (글자 격자와 코드)
js/world.js       지도 만들기, 바닥 칠하기, 충돌
js/data.js        물건, 가게, 대사, 할 일
js/entities.js    주인공, 마을 사람, 적
js/ui.js          대화창, 가게, 봇짐, 지도
js/main.js        시간, 고개의 규칙, 그리는 순서
```

외부 라이브러리는 쓰지 않았습니다. 그림 파일도 없습니다. 전부 실행할 때 캔버스에 찍습니다.
